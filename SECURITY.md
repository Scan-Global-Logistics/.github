# Security policy

This policy covers the `Scan-Global-Logistics` organisation and applies to every
repository in it.

## Reporting a vulnerability

Email **security@scangl.com**.

Tell us what you found, where you found it, and the steps to reproduce it. If
you can, say what an attacker would be able to do with it — that helps us
prioritise correctly on the first read. Screenshots, requests and proof-of-concept
code are all welcome.

Please **do not** open a GitHub issue, pull request or discussion for a security
report, and please give us a reasonable chance to fix the issue before you
disclose it publicly. We will not take legal action against researchers who
report in good faith, act in proportion, and avoid accessing or modifying data
that is not their own.

## What happens next

- We acknowledge every report we receive and will confirm we have it.
- We will tell you our assessment, whether we consider it in scope, and roughly
  when we expect a fix.
- We will let you know when it is resolved, and we are happy to credit you if
  you would like that.

We do not run a paid bug bounty programme.

## Scope

Our repositories are private and we publish no packages, so reports will
normally concern our public websites and internet-facing services rather than
code you can see here.

If your report is not about security — a bug in a service you use, or a
commercial matter — please use the
[contact page](https://www.scangl.com/contact/) instead.
