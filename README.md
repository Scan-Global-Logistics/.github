# .github

Organisation-wide defaults for **Scan Global Logistics**.

| File | What it does |
| --- | --- |
| `profile/README.md` | The page shown at [github.com/Scan-Global-Logistics](https://github.com/Scan-Global-Logistics) |
| `SECURITY.md` | How to report a security issue — applies to every repository in this organisation |
| `PULL_REQUEST_TEMPLATE.md` | Inherited by repositories that do not define their own |
| `ISSUE_TEMPLATE/config.yml` | Allows blank issues — each repository's GitHub issues are the tracker (Linear was, until October 2026) |

This repository is public so that GitHub can render the profile page and
inherit the templates. Everything else we build is private — see the
[profile page](https://github.com/Scan-Global-Logistics) for what this
organisation is and how to get in touch.
